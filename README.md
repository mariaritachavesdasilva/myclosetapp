# 👗 MyClosetApp

Aplicativo Android desenvolvido para facilitar a organização do guarda-roupa e tornar o dia a dia mais prático.

## 📱 Sobre o projeto

O **MyClosetApp** é um projeto de desenvolvimento mobile criado com o objetivo de explorar soluções tecnológicas para a organização pessoal.

A proposta do aplicativo é oferecer uma experiência simples e intuitiva, voltada para o universo da moda e para a organização das roupas.

## 🎯 Objetivo

Desenvolver um aplicativo Android que contribua para uma rotina mais organizada, utilizando recursos de desenvolvimento mobile e uma interface de fácil utilização.

## 🛠️ Tecnologias utilizadas

- Kotlin
- Android Studio
- Gradle
- Android SDK

## 📂 Estrutura do projeto

```text
myclosetapp/
├── app/
│   └── Código-fonte e recursos do aplicativo
├── gradle/
│   └── Configurações do Gradle
├── build.gradle.kts
├── gradle.properties
├── gradlew
├── gradlew.bat
└── settings.gradle.kts
```

## 🚀 Como executar o projeto

1. Faça o download ou clone este repositório.
2. Abra o Android Studio.
3. Clique em **Open**.
4. Selecione a pasta do projeto `myclosetapp`.
5. Aguarde a sincronização do Gradle.
6. Execute o aplicativo em um emulador Android ou dispositivo físico.
